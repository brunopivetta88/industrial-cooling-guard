# Security policy

This project is experimental. No release is certified for inline enforcement or safety-critical control. Only the latest main branch receives fixes on a best-effort basis.

For a suspected vulnerability, use GitHub's private vulnerability reporting if it is available for this repository. Otherwise open an issue requesting a private reporting channel without exploit details, infrastructure identifiers or operational captures. No guaranteed response time is offered.

For an incident affecting your facility, contact your internal incident-response team and equipment vendor through existing channels. Public project issues are not an emergency response service.
